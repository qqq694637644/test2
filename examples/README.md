# Examples

This directory contains standalone scripts that are not part of the installable
`vm_test_template` package or its public command-line interface.

## Snake game

Run the command-line Snake example from a repository checkout:

```text
python examples/snake_game.py --width 30 --height 15 --speed 8
```

Controls: `WASD` or arrow keys move, `P` pauses, and `Q` quits.
